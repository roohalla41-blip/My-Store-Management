# A2 Product and Engineering Blueprint

This folder defines the product skeleton before database implementation.

## Documents

- [Product blueprint](PRODUCT_BLUEPRINT.md): audience, product principles, modules, and delivery phases.
- [Screen map](SCREEN_MAP.md): complete navigation and page inventory.
- [Technical architecture](TECHNICAL_ARCHITECTURE.md): frontend boundaries, platform strategy, and future integration contracts.
- [Domain glossary](DOMAIN_GLOSSARY.md): business concepts and relationships, intentionally not a database schema.
- [Quality gates](QUALITY_GATES.md): acceptance criteria and release checks.

## Current phase: skeleton only

This phase may add navigation, page shells, design-system foundations, documentation, accessibility, and mock/empty states. It must not add or connect a database, authentication provider, payment gateway, live tax service, or real customer data. Do not represent planned capabilities as working features.

The existing local prototype and its storage key `a2_store_management_v1` must be preserved until a separately approved migration plan exists.
