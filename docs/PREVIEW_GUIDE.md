# A2 Interactive Skeleton Preview

## Preview link
For quick interactive review, use the raw.githack development preview:
https://raw.githack.com/roohalla41-blip/My-Store-Management/b772cde758705c38530bf236496a8205eb4c365c/preview/index.html

This is a convenience preview served by a third-party source proxy, not the permanent production deployment. If it is unavailable, open `preview/index.html` from this branch in a local static server.

## What is included
- Responsive desktop/tablet/mobile navigation
- English-first professional dashboard
- Product catalogue, sales, customers, purchasing, suppliers, expenses
- Planned modules for POS, returns, quotes/orders, inventory, warehouses, cash, banking, accounting, branches, employees, reports, notifications, tasks, integrations, settings, and help
- Search, local table filtering, sample status badges, sample charts, action dialogs, and mobile navigation

## Safety and scope
- All displayed business data is fictional sample data.
- Actions are UI demonstrations only and do not save records.
- No database, SQL, Supabase, authentication, payment gateway, or external business integration is connected.
- This preview is isolated under `preview/` and does not replace the root app shell.
- The temporary preview service is not guaranteed uptime. Use a dedicated deployment when a durable preview domain is needed.
